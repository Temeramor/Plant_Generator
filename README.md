# Voxel Flora (Godot 4.x)

Процедурная воксельная растительность (воксель 0.1 м), зависящая только от сида.

Запуск: откройте папку в Godot, нажмите F5. Сид — переменная `world_seed` у узла Main
(или аргумент `-- --seed=777`). ПК: WASD + пробел, мышь — как "палец" (эмуляция тача).

Настройки: `scripts/chunk_gen.gd` (GRASS_CLUMPS), `scripts/world.gd` (view_radius, lod0_radius),
параметры пород и размеров — профили в `scripts/trees/`.

## Режим сравнения пяти деревьев

В ветке `feature/five-tree-comparison` карта содержит ровно пять деревьев — по одному каждого типа. Случайный спавн остальных деревьев отключён. Деревья закреплены за чанками и стоят в центре своего чанка:

- Дуб: чанк `(2, 2)`.
- Берёза: чанк `(-2, 0)`.
- Конский каштан: чанк `(2, 0)`.
- Тополь: чанк `(0, -2)`.
- Ель: чанк `(0, 2)`.

Координаты указаны в чанках относительно начала мира. Сиды меняют форму деревьев, но не их вид или позиции. Генерация кустов, камней, цветов и травы оставлена прежней. Дальние деревья строятся из той же базовой геометрии с последующим downsample, а не перегенерируются в другой форме.

## Размеры деревьев

Размеры в `plant_gen.gd` задаются в ячейках по 0,1 м, а параметры каждой породы вынесены в `scripts/trees/`. Форма дерева зависит от сида. Палитры настроены под летнюю окраску отдельных пород; случайная осенняя окраска отключена для корректного сравнения.

- Дуб: 20–28 м, очень толстый ствол, низкие широкие ветви и отдельные широкие шумовые пучки листвы с просветами.
- Берёза: 15–24 м, раскидистая крона с ниспадающими ветвями и шероховатой листвой.
- Конский каштан: 18–27 м, широкая крона с низко начинающимися длинными и толстыми ветвями.
- Тополь: 22–35 м, ветви направлены вверх, крона вытянута вертикально.
- Ель: 22–37 м, конусовидная оболочка хвои с просветами возле ствола.

Для дальних чанков дерево строится сразу в сетке 0,2 м, сохраняя примерный физический размер. Это заменяет построение полной сетки 0,1 м с последующим downsample и снижает объём работы для дальнего LOD.
