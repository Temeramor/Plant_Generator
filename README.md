# Voxel Flora (Godot 4.x)

Процедурная воксельная растительность (воксель 0.1 м), зависящая только от сида.

Запуск: откройте папку в Godot, нажмите F5. Сид — переменная `world_seed` у узла Main
(или аргумент `-- --seed=777`). ПК: WASD + пробел, мышь — как "палец" (эмуляция тача).

Настройки: `scripts/chunk_gen.gd` (TREE_DENSITY, GRASS_CLUMPS), `scripts/world.gd` (view_radius, lod0_radius),
параметры пород и размеров — `PlantGen._params` в `scripts/plant_gen.gd`.

## Размеры деревьев

Размеры в `plant_gen.gd` задаются в ячейках по 0,1 м. Высота и форма каждого дерева по-прежнему зависят от сида. Примерные диапазоны взрослых деревьев:

- Дуб: 18–28 м, широкая крона.
- Берёза: 15–24 м, более узкая крона.
- Конский каштан: 17–27 м, широкая крона.
- Тополь: 22–35 м, высокая и относительно узкая крона.
- Ель: 22–37 м, конусовидная крона.

Для дальних чанков дерево строится сразу в сетке 0,2 м, сохраняя примерный физический размер. Это заменяет построение полной сетки 0,1 м с последующим downsample и снижает объём работы для дальнего LOD.

Android: Project > Install Android Build Template, Project > Export > Android, ориентация уже landscape,
рендерер GL Compatibility.
